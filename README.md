# AI-Rock_Paper_Scissor_game
A build i simple rock paper scissor game but with a twist with every round the game model train itself on previous data. Every person has a style of playing , a pattern which it follows , my model works on bayes predection to crack it
tools used - Bayesian ML model , flask 
# Structural design - Flask interface for basic game play (Using LLMS) -> for minimum 10 values it will generate random results -> then after 10 rounds it will starts training data using bayesian model and generate output based upon highest probability of output.
